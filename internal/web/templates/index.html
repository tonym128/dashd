Welcome to dashd

No usage has been recorded yet. dashd fills itself from your coding agents' own logs, or from other machines that push to it.

  1. On this machine: run dashd scan (or keep dashd serve-and-scan running). The Sources table below shows which agents were found and where dashd looked.
  2. From other machines: start this server with -ingest-token, then on each machine run 
    curl -fsSL https://raw.githubusercontent.com/tonym128/dashd/main/packaging/install.sh | bash
    or on Windows irm https://raw.githubusercontent.com/tonym128/dashd/main/packaging/install.ps1 | iex.
  3. Pricing: run dashd update-models so every model is priced.
